<h2><a href="https://leetcode.com/problems/running-sum-of-1d-array">Running Sum of 1d Array</a></h2> <img src='https://img.shields.io/badge/Difficulty-Easy-brightgreen' alt='Difficulty: Easy' />

## approach:

- Created empty list, initialized total = 0
- Iterating through given list by for loop
- Adding the current element to total
- Append the updated total to the runningSum list
- return total after list ends

- Time complexity: O(n)
- Space complexity: O(n)
