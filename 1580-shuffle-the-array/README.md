<h2><a href="https://leetcode.com/problems/shuffle-the-array">Shuffle the Array</a></h2> <img src='https://img.shields.io/badge/Difficulty-Easy-brightgreen' alt='Difficulty: Easy' />

## approach:

- Created empty list
- Iterating through each element using for loop
- First append command element at 0th index
- Next append command adds the number at current index plus the the given index 'n' that adds element from 2nd half of list
- return array with the elements

- Time Complexity: O(n)
- Space complexity:O(n)
