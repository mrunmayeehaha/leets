<h2><a href="https://leetcode.com/problems/jewels-and-stones">Jewels and Stones</a></h2> <img src='https://img.shields.io/badge/Difficulty-Easy-brightgreen' alt='Difficulty: Easy' />

## approach:


- Initialized count to 0
- Traverrsed through string stones with for loop
- If current element of stones in jewels, increment count
- Return count after list ends

- Time complexity: O(s * j)
- Space complexity: O(1)
