<h2><a href="https://leetcode.com/problems/contains-duplicate">Contains Duplicate</a></h2> <img src='https://img.shields.io/badge/Difficulty-Easy-brightgreen' alt='Difficulty: Easy' />

## approach:


- imported Counter from collections module
- stored frequency of array in variable count, initialized i = 0
- iterated through the frequncy array using for loop
- if frequency of current element is greater than or equal to 2, return True
- Else, return False

- Time complexity: O(n)
- Space complexity:O(1)
