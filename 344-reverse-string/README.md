<h2><a href="https://leetcode.com/problems/reverse-string">Reverse String</a></h2> <img src='https://img.shields.io/badge/Difficulty-Easy-brightgreen' alt='Difficulty: Easy' />

## approach:


- initialized left and right pointers to start and end of array
- traversed through array using for loop
     - while left is less than right
     - if element at left is equal to element at right, increment left and decrement right
     - else, swap elements between left and right

- Time complexity: O(n)
- Space complexity: O(1)
