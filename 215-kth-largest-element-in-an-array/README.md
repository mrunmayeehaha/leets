<h2><a href="https://leetcode.com/problems/kth-largest-element-in-an-array">Kth Largest Element in an Array</a></h2> <img src='https://img.shields.io/badge/Difficulty-Medium-orange' alt='Difficulty: Medium' />

## approach:

- store length of list in n variable
- sort list
- return the element at kth position by subtracting length and given value of k

- Time complexity: O(n logn)
- Space complexity: O(n)
