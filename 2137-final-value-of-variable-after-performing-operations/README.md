<h2><a href="https://leetcode.com/problems/final-value-of-variable-after-performing-operations">Final Value of Variable After Performing Operations</a></h2> <img src='https://img.shields.io/badge/Difficulty-Easy-brightgreen' alt='Difficulty: Easy' />

## approach:


- Initialized variable x to 0
- Traversing through operations list with i starting from 0
- If + operator in i, increment x by 1
- Else, decrement x by 1
- Return x

- Time complexity: O(n)
- Space complexity: O(1)
